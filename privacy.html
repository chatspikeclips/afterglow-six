Privacy policy

Last updated 21 November 2026.

Afterglow Six Studio is a private tool used only by the owner of the Afterglow Six YouTube channel.

What it accesses

Through YouTube API Services, with the owner's permission, it uploads videos to the owner's channel, reads that channel's basic details, and reads that channel's YouTube Analytics reports. It does not access any other user's data.

Where data is kept

The sign-in token and the analytics numbers are stored only on the owner's own computer. Nothing is sold, shared or sent to anyone else.

Removing access

Access can be removed at any time at Google Account permissions.
